# 爆款选题推送系统 Skill

> 作者：金三（@AI金三）
> 适用：Cola / Claude Code / 任何支持 Skill 的 AI Agent
> 触发方式：`/选题推送`、`/爆文推送`、「帮我推送今日选题」、「开始选题参谋」

---

## 这是什么

一个自动抓取低粉爆文数据、分析选题价值、定时推送到你手机的系统。

每隔几小时，它会帮你盯着爆文榜，挑出跟你内容方向最匹配的文章，分析为什么火、对你有什么参考价值，然后直接推到你的飞书或微信。

**你每天需要做的事：看推送，选一个，开始写。**

---

## 安装前准备

### 第一步：选数据源

**选项 A：次幂数据（精准，付费）**
- 注册地址：https://www.cimidata.com
- 需要付费会员才能看低粉爆文数据
- 优点：数据精准，按领域筛选，有热度/转发数据
- 配置方法：在 Chrome 里登录次幂数据，保持 Chrome 开着即可（Skill 会复用你的登录状态）

**选项 B：免费数据源（够用，免费）**
- 不需要任何账号
- Skill 会让 AI 直接搜索"近24小时AI领域热门公众号文章"
- 优点：零门槛，免费
- 缺点：精准度低于次幂数据，偶尔会有重复

### 第二步：选推送渠道

**选项 A：飞书**
- 需要创建飞书应用，拿到 AppID 和 AppSecret
- 教程：https://open.feishu.cn → 创建应用 → 机器人能力 → 获取凭证
- 把机器人加入你的目标群，记下群的 chat_id

**选项 B：微信（Cola ClawBot）**
- 需要先把微信接入 Cola，下面有完整步骤
- 接通之后不需要额外配置，直接用

### 微信 ClawBot 接入步骤

**第一步：确认 Channel 状态**

在终端运行：
```bash
cola channel list
```
查看 WeChat 状态：
- `connected` → 已接通，跳过下面步骤
- `disconnected` / `not configured` → 继续第二步

**第二步：扫码登录**

```bash
cola channel login wechat --qr-file /tmp/cola-wechat-qr.png
```

运行后打开 `/tmp/cola-wechat-qr.png`，用微信扫码。

> ⚠️ 二维码有效期约 2 分钟，过期重新运行上面命令

**第三步：验证连接**

再次运行 `cola channel list`，确认 WeChat 显示 `connected`，然后在微信里给 ClawBot 发一条消息测试。

**常见问题：**
- 扫了没反应 → 检查网络，重启 Cola 再试
- connected 但不回复 → 确认 Cola 在前台运行
- 合盖后断联 → 终端运行 `caffeinate -s &` 阻止睡眠

## 执行逻辑（AI 按此流程运行）

```
1. 获取数据
   - 如果用次幂数据：
     curl -s "http://localhost:3456/new?url=https://www.cimidata.com/articles/hit/1Y3Ka9jq"
     等待5秒，提取页面文章列表（标题、公众号、阅读、转发、热度）
   - 如果用免费数据源：
     搜索"近24小时 AI 领域热门公众号文章 阅读量过万 低粉账号"

2. 筛选3篇
   优先选：教程类、个人案例类、技巧类
   排除：营销号、机构媒体、与用户内容方向无关的

3. 逐篇分析
   - 为什么火（标题公式/内容类型/底层逻辑，3点）
   - 对用户的参考价值（结合用户填写的内容方向）
   - 给出1个具体选题建议

4. 汇总3个今日选题建议

5. 推送
   - 飞书：lark-cli im +messages-send --chat-id [chat_id] --text [内容] --as bot
   - 微信：通过当前 Cola 微信 channel 回复

6. 去重
   每次推送的爆文尽量不与上一次完全重复
   如果当天没有新文章，从近3天数据里选
```

---

## 注意事项

- **次幂数据用户**：Chrome 必须保持开着，Skill 才能抓取数据；Chrome 关闭时该次推送自动跳过
- **飞书用户**：确保机器人已加入目标群，且有发消息权限
- **微信用户**：需要先在微信里给 ClawBot 发一条消息激活通道
- 推送频率建议：2-4小时一次，太频繁会刷屏，太少会错过当天热点

**Skill 安装后，AI 应立即主动开始以下引导对话，不需要用户说任何话。**

### AI 引导脚本（按顺序执行，每次只问一个问题）

> 先来配置一下，5分钟搞定。

---

**Q1 — 内容方向**

→ 记录用户回答，继续 Q2

---

**Q2 — 数据源**
> 数据源选哪个？

> A. 次幂数据（精准，需要付费账号）
> B. 免费数据源（够用，零门槛）

→ 如果选 A：
> 好，请先在 Chrome 里登录 cimidata.com，登进去之后回来告诉我一声。Chrome 要保持开着，我抓数据的时候会用到。

→ 如果选 B：直接继续 Q3

**Q3 — 推送渠道**
> 推送到哪里？
> 
> A. 飞书
> B. 微信

→ 如果选 A：

> 2. AppSecret
> 3. 目标群的 chat_id（oc_ 开头）
>

> 还没接通，帮你连一下。运行这个命令，然后打开生成的图片扫码：
> ```

验证通过后继续 Q4。

---

**Q4 — 推送频率**
> 多久推一次？推荐 2-4 小时，输入小时数就行：

→ 记录用户回答

**配置完成，创建定时任务，发送确认消息：**

> 配置完成！我已经设置好了，每 X 小时自动推送一次。
