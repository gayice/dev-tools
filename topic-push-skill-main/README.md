# 爆款选题推送系统

> 每隔几小时，自动帮你盯着低粉爆文榜，推送3条分析好的选题建议到飞书或微信。
> 
> by [金三](https://github.com/ren644) · AI工具 + ADHD + 个人成长

---

## 它能做什么

- 自动抓取 AI 领域低粉爆文数据
- 分析每篇为什么火、对你有什么参考价值
- 给出具体选题建议
- 定时推送到你的飞书群或微信

**你每天需要做的事：看推送，选一个，开始写。**

---

## 安装方法

### 在 Cola 里安装

```
/install https://github.com/ren644/topic-push-skill
```

### 手动安装

把 `SKILL.md` 复制到你的 Cola MOD 的 skills 目录下即可。

---

## 快速配置

安装后告诉 AI：

```
帮我配置爆款选题推送系统
```

按引导填入：
- 数据源（次幂数据 or 免费）
- 推送渠道（飞书 or 微信）
- 你的内容方向
- 推送频率

大概5分钟配置完，之后自动跑。
